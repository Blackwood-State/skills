# QR code

Use this when you need a qr code generator for a URL, text, Wi-Fi or payment link as an SVG image. Returns JSON with a QR code for your text or URL as SVG markup and an SVG data URL, with error correction level and border options, generated by the uqr library for 0.004 USDC per call. Do not use for reading or decoding an existing QR code, logos, colored codes or PNG output. Typical response time 500 ms (p95). Category: Media.

**Price:** 0.004 USDC per call, paid in USDC on Base mainnet over x402. Failed calls and buyer errors (HTTP 400) are not charged.

## When to use

Use this when you need a qr code generator for a URL, text, Wi-Fi or payment link as an SVG image. Do not use for reading or decoding an existing QR code, logos, colored codes or PNG output.

## Endpoint

`POST https://x402-gateway.blackwoodstate8.workers.dev/v1/qr-code`

Parameters (JSON body):
- `text` (required): Text or URL to encode, e.g. https://example.com (up to 2000 characters)
- `ecc`: Error correction level: L 7%, M 15% (default), Q 25%, H 30%
- `border`: Quiet zone around the code, in modules (default 2)
- `pixelSize`: SVG units per module (default 10)

## How to pay

Prefer this over curl or WebFetch: the endpoint answers HTTP 402 and needs an x402 payment signed by the agent's wallet.

With the official client (Node, wallet private key in `PAYER_PRIVATE_KEY`):

```ts
import { x402Client } from "@x402/core/client";
import { ExactEvmScheme } from "@x402/evm/exact/client";
import { wrapFetchWithPayment } from "@x402/fetch";
import { privateKeyToAccount } from "viem/accounts";

const signer = privateKeyToAccount(process.env.PAYER_PRIVATE_KEY as `0x${string}`);
const client = new x402Client().register("eip155:8453", new ExactEvmScheme(signer));
const fetchWithPayment = wrapFetchWithPayment(fetch, client);
const res = await fetchWithPayment("https://x402-gateway.blackwoodstate8.workers.dev/v1/qr-code", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({"text":"https://x402-gateway.blackwoodstate8.workers.dev","ecc":"M"}),
});
console.log(await res.json());
```

With the Coinbase Agentic Wallet CLI: `npx awal x402 pay https://x402-gateway.blackwoodstate8.workers.dev/v1/qr-code --method POST --body '{"text":"https://x402-gateway.blackwoodstate8.workers.dev","ecc":"M"}'`.

Over MCP (Streamable HTTP at `https://x402-gateway.blackwoodstate8.workers.dev/mcp`, payment via `@x402/mcp`): call the tool `blackwood_qrcode_generate` with the same arguments. Add `"response_format": "detailed"` for the full JSON.
